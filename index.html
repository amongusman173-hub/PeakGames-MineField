HOW TO PLAY

THE BASICS
  • Left Click Reveal a tile
  • Right Click Flag a suspected mine
  • Numbers show how many mines are in the 8 surrounding tiles
  • Reveal every safe tile to clear the floor
TRY IT — MINI MINEFIELD

Left click to reveal · Right click (or FLAG button) to flag · Clear all safe tiles to win

ROGUELIKE RULES
  • You have 3 lives ❤️ — each mine hit costs one
  • Lose all lives = permadeath, run ends
  • After each floor visit the 🛒 SHOP to buy perks & upgrades
  • Every 3rd floor is a ⚠ BOSS FLOOR with special rules
  • Earn 💎 gems to spend in the Gacha Machine between runs
  • Earn ⚡ EXP to unlock permanent skills in the Skill Tree

🔒 PRIVACY POLICY

Last updated: April 2026

1. What We Collect

MINEFIELD is a browser-based game that runs entirely in your browser. We do not collect, store, or transmit any personally identifiable information (PII) to our servers.

The following data is stored locally on your device only using localStorage:

  • Game progress (score, gems, EXP, unlocked skills)
  • Inventory items and equipped loadout
  • Settings preferences (volume, VFX, screen shake)
  • Run modifier selections
  • Best score and run count

This data never leaves your device and is not accessible to us.

2. Third-Party Services

MINEFIELD uses MantleDB (mantledb.sh) for optional live broadcast features (announcements, polls). If these features are active, anonymous event data may be sent to MantleDB's servers. No personal information is included. Please review MantleDB's privacy policy for details.

Google Fonts are loaded from Google's CDN for typography. Google may collect standard request logs. See Google's Privacy Policy.

3. Cookies

We do not use cookies. All game data is stored in localStorage, which is not transmitted with HTTP requests.

4. Analytics

We do not use any analytics, tracking pixels, or telemetry. No usage data is collected.

5. Children's Privacy

MINEFIELD does not knowingly collect data from children under 13. Since no data is collected at all, the game is safe for all ages.

6. Data Deletion

You can delete all locally stored game data at any time via Settings → Reset All Progress, or by clearing your browser's localStorage for this site.

7. Changes

If this policy changes, the "Last updated" date above will be revised. Continued use of the game constitutes acceptance of any updates.

8. Contact

Questions? This is an indie game — reach out via the game's community channels.
